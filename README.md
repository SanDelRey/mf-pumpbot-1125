A breadth-velocity bot for the pump.fun replay sprint: it buys a young coin once enough distinct wallets have bought it inside a short slot window (or a wider crowd inside a longer one), sized to the curve's 1% order cap, and exits on a 40% take-profit, a 20% stop or 100 slots.

## Run it

```sh
node main.ts
```
